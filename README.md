# Aster

Aster is a scientific computing and AI inference service built incrementally, starting with a local matrix calculator and evolving towards distributed CPU and GPU workloads.


## First milestone

Build a command-line program that reads two matrices from a JSON file,
validates their dimensions, multiplies them without numerical libraries,
and writes the result to a JSON file.


Invalid input should produce a clear error message and nonzero exit code.

## Learning approach

I write the implementation, with AI guidance for explanations and review.
I record what I learn, mistakes I encounter, and engineering decisions in a learning journal.

Each milestone includes acceptance criteria, relevant tests, documentations, and focused Git commits.
